# 📐 Kalkulator Segitiga — inikatik

Proyek tugas **Fundamental Software Engineering** — RevoU.

Kalkulator Segitiga (inikatik) adalah web app sederhana berbasis HTML, CSS, dan JavaScript yang membantu pengguna menghitung **luas** dan **keliling** segitiga secara cepat dan mudah langsung dari browser.

> 🌱 **Catatan pribadi:** Ini adalah **proyek pemrograman pertama saya**, dibuat sebagai bagian dari **bootcamp pertama** yang saya ikuti. Proyek ini menandai langkah awal saya belajar coding dari nol, jadi masih banyak yang bisa disempurnakan — kritik dan saran sangat terbuka! 🙌

🔗 **Demo:** [https://dzikrinajauza.github.io/27-nov-23-dzikrinajauza/index.html](https://dzikrinajauza.github.io/27-nov-23-dzikrinajauza/index.html)

## ✨ Fitur

- **Hitung Luas Segitiga** — input alas dan tinggi, hasil luas langsung ditampilkan.
- **Hitung Keliling Segitiga** — input sisi 1, sisi 2, dan sisi 3, hasil keliling langsung ditampilkan.
- Tampilan sederhana dan ringan, langsung berjalan di browser tanpa instalasi.

## 🖥️ Tampilan Halaman

| Halaman | Deskripsi |
|---|---|
| `index.html` | Halaman utama / landing page berisi sambutan dan tombol menuju kalkulator. |
| `start.html` | Halaman kalkulator berisi form untuk menghitung luas dan keliling segitiga. |

## 🛠️ Teknologi yang Digunakan

- **HTML** — struktur halaman.
- **CSS** — tampilan dan gaya halaman.
- **JavaScript** — logika perhitungan luas dan keliling segitiga.

1. Clone atau download repository ini.
   ```bash

   ```
2. Masuk ke folder proyek.
   ```bash
   cd 27-nov-23-dzikrinajauza
   ```

## 📌 Cara Penggunaan

**Menghitung Luas:**
1. Masukkan nilai **alas** segitiga.
2. Masukkan nilai **tinggi** segitiga.
3. Klik tombol **Hitung Luas**.

**Menghitung Keliling:**
1. Masukkan nilai **sisi 1**.
2. Masukkan nilai **sisi 2**.
3. Masukkan nilai **sisi 3**.
4. Klik tombol **Hitung Keliling**.
